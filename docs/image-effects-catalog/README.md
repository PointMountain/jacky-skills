# Image Effects Catalog

这是 `image-effects` 八效果目录的长期设计入口。规格已经批准，实现已完成并通过本地与 GitHub 检查；合并后的源仓库提交仍是公开导出与 Pages 发布的唯一事实源。

本主题覆盖固定效果集合、来源与许可证、效果卡和 Gallery 契约、独立预览策略、验收门以及发布边界。需要维护这些长期约束时，读取 [`references/design.md`](references/design.md)；需要批量新增或重做 Gallery 预览时，读取 [`references/preview-production.md`](references/preview-production.md)。一次性的执行步骤已经在实施完成后删除，不作为持续维护协议。

当前发布范围明确排除 `grade-images`、Happy App 修改、远程目录、OSS/CDN 与 OTA。
