## Chunk 1: 创建 SKILL.md 和注册

### Task 1: 创建 ob-rate 目录和 SKILL.md

**Files:**
- Create: `plugins/obsidian-tools/ob-rate/SKILL.md`

- [ ] **Step 1: 创建目录**

```bash
mkdir -p plugins/obsidian-tools/ob-rate
```

- [ ] **Step 2: 写入 SKILL.md 完整内容**

创建 `plugins/obsidian-tools/ob-rate/SKILL.md`，内容包含以下部分：

**Frontmatter**（遵循现有模式）：
```yaml
---
name: ob-rate
description: "Obsidian 文章质量评分系统。通过交互式问答对知识库文章打分，记录缺点，自动提炼写作偏好。触发词：评分、打分、文章评价、ob-rate。"
---
```

**元数据标签**（遵循现有模式）：
```xml
<role>Obsidian 知识库质量评分助手，通过交互式问答让用户对文章进行主观质量评分，记录问题并自动提炼写作偏好。</role>
<purpose>建立人机结合的质量反馈闭环：用户评分 → 记录问题 → 提炼偏好 → 指导后续写作和采集。</purpose>
<trigger>
触发词和示例
</trigger>
<gsd:workflow>四阶段流程</gsd:workflow>
```

**正文指令**包含以下章节：

1. **配置检查** — 检查 OBSIDIAN_REPO、wiki/ 目录、评分文件
2. **数据文件** — `.ratings.md` 和 `.rating-preferences.md` 的完整模板
3. **执行流程** — 四个阶段的详细指令：
   - 第一步：选择文件夹（扫描目录、展示选项）
   - 第二步：逐篇评分（展示全文、解析输入、记录数据）
   - 第三步：批量统计（每5篇触发、更新偏好）
   - 第四步：文件夹完成（展示总结、选择下一步）
4. **偏好提炼逻辑** — 提炼规则和输出格式
5. **输入解析规则** — 分数解析、问题标签提取、命令处理
6. **边界条件** — 异常场景处理表
