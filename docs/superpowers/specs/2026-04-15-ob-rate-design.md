# ob-rate: Obsidian 文章质量评分系统

## 概述

为 obsidian-tools 插件新增 `ob-rate` skill，通过交互式问答让用户对知识库文章进行质量评分。系统记录每篇文章的分数和缺点，自动提炼用户的写作偏好，持续迭代优化知识库质量标准。

## 需求背景

用户对知识库中的文章质量不满意，但难以系统性描述问题。需要一个机制：
- 逐篇评价，记录具体问题
- 从评价中学习用户偏好（什么是好文章、什么是差文章）
- 支持按文件夹（主题目录）分批处理
- 偏好模型随评分积累持续迭代

## 设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 评分方式 | 展示全文，用户直接打分+说缺点 | 最直接，获取真实主观反馈 |
| 存储格式 | 单个 Markdown 文件 | OB 可见可搜索，69篇文章单文件可管理 |
| 偏好提炼 | 自动提炼，每5篇触发 | 减少用户负担，持续积累洞察 |
| 评分范围 | 按文件夹选择，评完一个目录再换下一个 | 聚焦一个主题，避免疲劳 |
| 评后动作 | 纯评分，不修改文章 | 先记录问题，后续通过其他 skill 修复 |

## 交互流程

### 启动阶段

1. 读取 `OBSIDIAN_REPO` 配置
2. 扫描 `wiki/` 下所有主题目录，统计每个目录的文章数量
3. 读取 `wiki/.ratings.md` 获取已评分文章列表
4. 展示主题目录列表（含文章数、已评数），用户选择一个文件夹

```
📊 文章评分系统

主题目录：
  1. ai/ (3篇, 已评0篇)
  2. claude/ (8篇, 已评3篇)
  3. current-affairs/ (10篇, 已评0篇)
  ...

选择要评分的文件夹（输入编号）：
```

### 评分阶段

选中文件夹后，逐篇展示未评分的文章：

```
━━━ [3/8] claude/Skills-分享与同步.md ━━━

[展示文章全文]

请评分（1-10）并说明缺点：
（输入分数和意见，如 "7分，太长，缺代码示例"）
（输入 s 跳过，输入 q 结束本轮）
```

用户回复后：
- 解析分数（1-10 的整数）
- 提取问题标签（从用户描述中提取关键词）
- 记录用户原始评价
- 追加到 `wiki/.ratings.md` 的评分记录表
- 更新统计信息

### 批量统计（每5篇触发）

每评完 5 篇，展示本轮统计并更新偏好：

```
📊 本轮统计（已评5篇）

- 平均分：6.4
- 常见问题：太长(3次), 缺引言(2次), 概念不清(2次)
- 高分文章：CLI-基础分享(9分)
- 低分文章：xxx(3分)

🧠 偏好更新
新增规则：
  - 偏好有引言段落的文章
  - 不喜欢跳过基础概念

继续评分剩余 3 篇？
```

### 文件夹完成

一个文件夹评完后：

```
✅ claude/ 目录评分完成

总评 8 篇，平均分 6.8
偏好文件已更新

选择下一个文件夹？还是结束？
```

## 偏好提炼逻辑

### 触发时机

- 每评完 5 篇
- 文件夹评分结束时（不足 5 篇的余量）
- skill 启动时读取已有偏好作为上下文

### 提炼规则

1. **问题频率统计**：统计所有问题标签的出现次数，高频问题 = 核心关注点
2. **分数-问题关联**：分析哪些问题与低分强相关（出现该问题的文章平均分 < 5）
3. **高分特征提取**：提取 8 分以上文章的共同特征
4. **增量更新**：新评分数据与已有偏好合并，补充或修正规则

### 偏好文件结构

```markdown
## 高分文章特征（≥8分）
- 有清晰引言，说明文章目标
- 结构分段明确，每段一个主题
- 包含代码示例或具体数字

## 低分文章特征（≤5分）
- 缺少引言，直接进入细节
- 概念跳过基础解释
- 纯文字无代码/表格

## 偏好规则
1. 偏好短文（≤500字，平均得分 7.2 vs 长文 5.1）
2. 重视引言段落（有引言平均 8.0 vs 无引言 4.5）
3. 不喜欢概念跳过基础（出现此问题的文章平均分 3.8）
```

## 边界条件

| 场景 | 处理 |
|------|------|
| 文件夹所有文章已评分 | 提示用户选择其他文件夹 |
| 用户输入非数字 | 提示重新输入（如"请输入1-10的分数"） |
| 用户输入 s 跳过 | 跳过当前文章，继续下一篇 |
| 用户输入 q 结束 | 保存当前进度，展示已评统计 |
| 评分文件不存在 | 首次使用，创建模板文件 |
| 中途退出 Claude | 进度已保存在文件中，下次启动自动恢复 |

## 与现有 skill 的关系

| 关联 skill | 关系 |
|------------|------|
| ob-tidy | ob-tidy 做自动检查，ob-rate 做主观评分，互补 |
| ob-collect | 采集新文章后，可引导用户评分 |
| ob-index | 评分表不参与索引 |
