04

Skill 怎么装 · 怎么分享

上面所有 skill 不是天生就在,要装。两条来源、两种装法:别人出的「外部 skill」统一用 Vercel 的 skills.sh(npx skills)装;自己出的「内部 skill」放 jacky-skills,用 git clone + 软链。两者都落到 ~/.claude/skills/,Claude Code 即扫即用。

🌐 外部 Skill → skills.sh

别人/官方出的 · 约 100+ 个
npx skills add <owner/repo> -g npx skills list / update / remove
Vercel 出的开放生态 CLI,自动识别已装的各 AI 工具,默认 symlink(单一副本多 agent 复用,易 update)。⚠ 国内它内部 clone GitHub 不走代理会失败,需先 export HTTPS_PROXY=http://127.0.0.1:10802。发现目录:skills.sh。

🛠️ 内部 Skill → git clone + 软链

自己开发的 · 统管在 jacky-skills
git clone …/jacky-skills j-skills link && j-skills install -g
自研 skill 全放 jacky-skills 仓库(plugins/ + skills/),用 j-skills 软链到 ~/.claude/skills/——改源即生效,免重装。本机 150+ 个 skill 大多是这种软链结构。

AI 做视频

三条路线
从省力到硬核三条路:① 网页录屏式(强推,最省力) → ② 代码渲染真 mp4 → ③ 采集·处理已有视频。
★ 强推 ★ web-video-presentation文章/口播稿 → 伪装成视频的 16:9 网页 · 点击驱动 · 录屏即成片
↑ 来自 ConardLi/garden-skills(本地已有) · 内置 10 套主题(不止一种风格) + Vite/React 脚手架模板 · 底层只用 ffmpeg 合音频,非真渲染
代码渲染 mp4 RemotionReact 组件 → mp4 · 有预览/渲染管线 · 开发者向· HyperFramesHeyGen 开源 · 纯 HTML/CSS/JS → 无头浏览器抓帧 → mp4 · 无需 React,专为 agent
采集·处理 video-to-text视频 → 文案· audio-to-subtitle音视频 → 字幕(MLX-Whisper/豆包)· m3u8-dlHLS 下载· fix-neat-video修复分段视频· bilibili-batchB站批量 → Obsidian
