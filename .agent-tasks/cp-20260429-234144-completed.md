## 方案要点

### 新架构

```
OpenCLI（统一输入层）
├── 文章/文本内容 → ob-collect → Obsidian
└── 视频/音频内容 → 有字幕? → YES → ob-collect → Obsidian
                                → NO → OpenCLI download → audio-to-subtitle → ob-collect → Obsidian
```

### 文章流
- opencli web read / zhihu answer / 36kr article → ob-collect

### 视频流
- opencli bilibili subtitle / youtube transcript → 有字幕直接用
- 无字幕 → opencli download → audio-to-subtitle (ASR) → ob-collect
