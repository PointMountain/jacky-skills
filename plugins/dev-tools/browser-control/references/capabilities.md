# Browser Control 能力地图

本机网页自动化只有一个能力槽位；本文件不承诺运行时可用性，实际任务必须先做只读最小探测。

## browser_automation

适用：打开网页、复用登录态、填写与点击、截图、DOM 提取、前端调试、网页 QA 和已验证流程回归。

- 唯一候选：`ego-ops`，实际浏览器运行时为 Ego Lite 的 `ego-browser`。
- 最小 probe：在 Ego Lite task space 中只读复核页面、登录态（如需要）与入口，并取得标题、结构快照或截图之一。
- 输入契约：脱敏目标描述、允许动作、禁止动作、风险、成功标准和所需证据。
- 输出契约：页面状态、动作结果、失败原因、task space 清理结果与脱敏证据引用。
- 验收：关键动作后重新观察；目标状态与所需证据必须同时成立。无法确认时 fail closed，不切换其他浏览器工具。
- 经验：Ego Ops 先读取 `experience.local.md`；成功且有明确根因、会改变下次决策的结论才写回。旧经验不是当前页面事实。

项目 Playwright E2E 不属于此槽位；它只在用户明确要求测试项目时独立运行。
