# 评估报告模板与产出文件

本文件定义了评估报告的 Markdown 模板、score.json 结构以及产出文件目录结构。

---

## 一、评估报告模板

```markdown
# Harness Evaluation Report

> 评估时间：{ISO-8601 时间戳}
> 评估模式：{前端设计 | 全栈开发}
> 评估对象：{目标描述}
> 评估轮次：第 {N} 次（如为多轮迭代）

---

## 总览

| 指标 | 值 |
|------|-----|
| **总分** | **{XX}/100** |
| **等级** | **{A/B/C/D/F}** |
| **结论** | ✅ 通过 / ❌ 不通过 |
| **一句话评价** | {精炼的总体判断} |
| **最强维度** | {维度名}：{分数} |
| **最弱维度** | {维度名}：{分数} |

---

## 维度评分

| 维度 | 分数 | 权重 | 加权分 | 趋势 |
|------|------|------|--------|------|
| D1: {维度名} | {s}/100 | {w}% | {ws} | {↑/↓/→} |
| D2: {维度名} | {s}/100 | {w}% | {ws} | {↑/↓/→} |
| D3: {维度名} | {s}/100 | {w}% | {ws} | {↑/↓/→} |
| D4: {维度名} | {s}/100 | {w}% | {ws} | {↑/↓/→} |
| **总计** | | **100%** | **{total}** | |

---

## 逐维度详情

### D1: {维度名} — {分数}/100

**评语**：{总体评价}

**支持证据**：
- ✅ {正面证据}
- ✅ {正面证据}
- ❌ {负面证据}

**扣分明细**：
| 扣分项 | 扣分 | 原因 |
|--------|------|------|
| {具体项} | -{n} | {说明} |

---

## 问题清单

### 严重（Blocker）
> 必须修复才能通过

- {问题描述 + 具体位置}

### 重要（Major）
> 强烈建议修复

- {问题描述 + 具体位置}

### 轻微（Minor）
> 建议优化

- {问题描述 + 具体位置}

---

## 改进建议

> 按优先级排序，面向生成器的可操作建议

### 战略建议
{如果分数趋势不好，建议转向不同方向}

### 具体修复项
1. **P0**：{具体到文件和行号的修复建议}
2. **P1**：{具体到文件和行号的修复建议}
3. **P2**：{具体到文件和行号的修复建议}

### 下轮重点
{指导生成器下一轮应优先关注什么}

---

## 评估元数据

| 字段 | 值 |
|------|-----|
| 评估耗时 | {X} 分钟 |
| 检查文件数 | {N} |
| 发现问题数 | Blocker:{n} / Major:{n} / Minor:{n} |
| 与上轮对比 | {↑n / ↓n / 首次评估} |
```

## 二、score.json 结构

```json
{
  "evaluatedAt": "{ISO-8601}",
  "mode": "frontend-design | fullstack-dev",
  "iteration": 1,
  "overallScore": 72,
  "grade": "B",
  "passed": true,
  "dimensions": {
    "d1": {
      "name": "{维度名}",
      "score": 75,
      "weight": 0.30,
      "weighted": 22.5,
      "evidence": ["{证据1}", "{证据2}"],
      "issues": ["{问题1}"]
    },
    "d2": { "..." : "..." },
    "d3": { "..." : "..." },
    "d4": { "..." : "..." }
  },
  "issues": {
    "blocker": [{ "description": "...", "location": "..." }],
    "major": [{ "description": "...", "location": "..." }],
    "minor": [{ "description": "...", "location": "..." }]
  },
  "recommendation": "pass | retry | rethink",
  "nextFocus": "{下轮重点}"
}
```

## 三、产出文件目录结构

```
.evaluator/
├── {timestamp}/
│   ├── report.md              # 完整评估报告（人类可读）
│   ├── score.json             # 机器可读评分数据
│   └── evidence/              # 评估证据目录
│       ├── screenshots/       # 页面截图（如适用）
│       └── code-snippets.md   # 关键代码片段
└── latest -> {timestamp}/     # 最新评估的软链接
```
