## 使用说明

### 动态获取

**推荐方式**：每次执行时调用 `list_projects` 获取最新映射

```javascript
// 伪代码
const projects = await list_projects();
const projectMap = {};
projects.forEach(p => {
  projectMap[p.id] = p.name;
});
```

- **收集箱（Inbox）**：projectId 为 `"inbox"` 或 `"inbox1019223045"`
- **已完成**：不是清单，而是任务状态 `status: 2`
- **已删除**：任务状态 `status: -1`
