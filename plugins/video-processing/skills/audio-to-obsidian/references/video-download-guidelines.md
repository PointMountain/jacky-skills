# 视频下载工具使用规范与免责声明

> 本文档适用于 jacky-skills 中所有涉及视频/音频下载的 skill（video-to-text、bilibili-to-obsidian、m3u8-dl 等）。

## 一、核心原则

**所有下载行为仅限个人学习与研究用途，严禁用于商业目的或二次分发。**

## 二、工具说明

本项目中涉及的视频下载 skill 底层依赖以下工具：

| 工具 | 用途 | 项目地址 |
|------|------|----------|
| yt-dlp | 视频流下载、字幕提取 | https://github.com/yt-dlp/yt-dlp |
| ffmpeg | 音视频格式转换、合并 | https://ffmpeg.org/ |
| m3u8-dl | HLS/M3U8 视频流下载 | 本项目 skill |

这些工具本身是开源合法的，关键在于使用方式。

## 三、安全使用规范

### 允许的使用场景

- 个人离线学习、观看
- 下载自己上传的内容
- 下载无版权 / Creative Commons 授权的内容
- 提取字幕用于语言学习
- 已购买付费内容的离线备份（个人使用）

### 禁止的使用场景

- 将下载内容上传到其他平台二次分发
- 批量下载用于商业盈利
- 绕过付费墙下载付费内容并分享
- 侵犯他人知识产权的任何行为

## 四、技术防护措施

为降低对平台的压力和法律风险，所有涉及批量下载的 skill 应遵循以下规则：

### 4.1 请求频率控制

```
- 单次下载间隔：≥ 3 秒
- 批量任务上限：单次不超过 50 个视频
- 连续运行时间：不超过 1 小时
- IP 被限制时：立即停止，等待至少 30 分钟后重试
```

### 4.2 使用建议

| 场景 | 建议 |
|------|------|
| 下载单个视频 | 正常使用，无需特殊处理 |
| 下载播放列表 | 控制并发数，加延时 |
| 下载 UP 主内容 | 仅下载需要的部分，避免全量采集 |
| 提取字幕/文案 | 优先选择仅下载字幕模式，不下载视频流 |

### 4.3 错误处理

遇到以下情况时 skill 应自动停止：

- HTTP 429（请求过于频繁）
- HTTP 403（访问被拒绝）
- 平台返回验证码要求
- 连续 3 次下载失败

## 五、法律风险说明

### 灰色地带

视频下载工具在全球范围内处于法律灰色地带：

- **中国**：《著作权法》允许个人学习、研究使用，但禁止传播
- **美国**：DMCA 禁止绕过 DRM，但个人离线使用的执法案例极少
- **欧盟**：部分国家允许个人备份，但禁止分享

### 历史案例

| 事件 | 时间 | 结果 |
|------|------|------|
| youtube-dl 被 GitHub 下架 | 2020.10 | RIAA 发起 DMCA，后因 EFF 介入恢复 |
| yt-dlp 被 GitHub 下架 | 2024.10 | 后经社区申诉恢复 |
| 各平台持续对抗下载工具 | 持续中 | YouTube 定期更新加密算法 |

**结论**：版权方一直在关注此类工具，个人少量使用风险极低，但批量商业使用有明确法律风险。
