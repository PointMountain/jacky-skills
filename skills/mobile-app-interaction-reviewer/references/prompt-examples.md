# Mobile App 交互评审 Prompt

## 手机截图评审

```text
使用 $mobile-app-interaction-reviewer 的截图评审模式检查这张手机截图。先确认平台、方向、键盘与系统栏，再检查核心任务、固定区域、小屏信息预算、触控入口候选、安全区和弹层边界。只报告画面能证明的问题；触控、手势和键盘未知项写成验证问题，不要用 PC 的 hover/Tooltip 方案修复移动端发现性，也不要修改代码。
```

## 移动交互走查

```text
使用 $mobile-app-interaction-reviewer 只读走查 {App/URL 与流程}。设备条件为 {平台、设备/视口、方向、字体缩放}。按真实触控路径覆盖核心状态、软键盘、系统返回、长内容、安全区和相关弹层；逐 Case 返回动作前后证据、verdict、P0–P3 问题与未覆盖原因。Mobile Web 证据不能冒充原生手势、键盘或安全区通过。
```

## 修复后回归

```text
使用 $mobile-app-interaction-reviewer 的回归验收模式复测 {问题清单/Case}。冻结原设备条件、方向、字体/显示缩放、键盘与数据状态，严格复跑原触控路径；每个可见 Case 独立交付前后证据。只输出已修复、仍失败、证据不足、阻断和路径内新增回归，不扩展为全站探索，也不要修改代码或发布。
```
