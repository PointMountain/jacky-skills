# PC Web 交互评审 Prompt

## 截图快速评审

```text
使用 $pc-web-interaction-reviewer 评审这张 PC 页面截图。只报告当前画面有证据支持的交互与布局问题，按影响排序；每项说明位置、问题、用户影响、PC 端预期和置信度。最后给出最值得先改的 3 项，并单列需要浏览器实测的内容。不要修改代码。
```

## 指定页面评审

```text
使用 $pc-web-interaction-reviewer 评审这个 PC 页面：{URL 或页面路径}。重点检查信息层级、空间利用、操作入口、弹窗/下拉框、状态反馈、滚动、键盘与焦点。输出可复现问题和修复优先级，不要直接改代码。
```

## 全站交互走查

```text
使用 $pc-web-interaction-reviewer 对 {产品或 URL} 做 PC 全站交互走查。覆盖 1280×720、1440×900 和 1920×1080；逐页点击可见入口，检查打开、关闭、Esc、外点、长内容、空状态、错误状态和视口边界。输出覆盖表、P0–P3 问题、证据、PC 端预期及 E2E 验收标准。
```

## Agent 委派

```text
你是独立 PC Web 交互评审 Agent。使用 $pc-web-interaction-reviewer 只读评审 {截图、录屏、URL 或构建}，范围限定为 {页面或流程}。不要接受生产者自评作为结论，不要修改产物。返回按优先级排序的问题清单；每项包含复现位置、实际结果、用户影响、PC 端预期、证据等级和待验证项。
```

## 修复后回归

```text
使用 $pc-web-interaction-reviewer 回归以下 PC 交互问题：{问题清单或 ID}。按原复现路径复测，并补测窗口缩放、长内容、Esc、焦点恢复和重复打开。逐项输出已修复、仍失败、证据不足或新增回归；没有证据时不要判定通过。
```
