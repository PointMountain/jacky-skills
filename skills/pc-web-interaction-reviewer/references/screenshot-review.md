# 截图评审模式

> 用于静态视觉审查。只判断当前画面能够证明的内容，不执行页面交互，也不把截图推断包装成 E2E 结论。

## 进入条件

输入是截图、本地图片或录屏中的指定静态帧，目标是快速发现桌面端信息层级、空间利用、比例、遮挡、溢出和视觉一致性问题。连续录屏可以补充可见变化的时序证据，但仍不能替代当前运行态、DOM、Console 或 Network 的实测。

截图明显来自原生手机或窄屏 Mobile Web 时，停止本模式并改用 `$mobile-app-interaction-reviewer`；不要用 PC 的多栏、Hover/Tooltip 或浮层密度要求评判手机画面。

如果用户同时提供 URL，也只有在明确要求实测时才切换到“全站交互 E2E 走查”。静态评审阶段不要点击页面来混合证据。

## 一、登记证据边界

1. 记录截图对应的页面、已知视口、缩放比例和状态；未知项明确写“未知”。
2. 区分截图直接可见事实、用户补充的产品事实和运行态未知项。
3. 截图只能证明捕获时刻的画面，不能证明按钮可用、键盘行为、焦点顺序、动画、请求结果或修复已经生效。
4. 用户补充的“无法收起”“某端存在某功能”等信息可以作为用户确认的产品事实，但要与截图可见事实分栏记录。

## 二、先扫主矛盾

按以下顺序观察，先处理控制整屏体验的问题：

1. 最大的内容元素是否挤压核心任务。
2. 最大的无效空白是否来自不合理的固定区域、缺失状态、单侧闲置区域或宽度分配；没有边框或分隔线不代表该区域可以从盘点中消失。
3. 最小、最难读的文字是否与媒体、卡片或控件比例失衡。
4. 固定侧栏、顶栏、底部输入区或检查器是否长期侵占工作区。
5. 孤立入口是否在尺寸、描边、对齐、分组和语义上脱离同层级控件；不熟悉产品的用户能否在两秒内仅凭当前画面说出其大致用途、当前状态和退出方式。

对双栏、三栏或带检查器的工作区，先建立区域盘点，不要把整块空白只写成一个笼统问题：

| 区域 | 当前可见用途/内容 | 占用空间 | 可见收起入口 | 可见恢复路径 | 证据等级 |
|---|---|---|---|---|---|
| 左侧辅助区 |  |  |  |  |  |
| 核心工作区 |  |  | 不适用 | 不适用 |  |
| 右侧辅助区 |  |  |  |  |  |

区域边界可以是隐式的。若核心内容只占中间一段，而某一侧存在大块空白、贴边入口或与另一端明显不对称的闲置空间，把它登记为“候选辅助区/闲置侧翼”，继续确认它是阅读留白、缺失内容、折叠状态还是未利用的能力区。即使截图无法定性，也必须输出“什么状态会填充这里、窄屏或移动端对应能力是什么、能否独立收起”的验证任务，不能用“未见独立面板”结束检查。

对图标式全局模式入口，分别检查“用途能否识别”“当前是否启用”“如何退出”。截图中缺少文字、邻近上下文或状态表达时，可以确认当前画面的发现性不足；Tooltip、可访问名称和实际切换行为仍属于运行态待验证项。

PC 上 Tooltip 或悬浮说明可以补充次要解释，但单帧截图只能证明当前帧实际显示的内容。未出现的 Hover、键盘焦点等价入口和消失时机必须进入运行态待验证，不能靠实现惯例推断通过。

截图顶边或滚动容器边缘出现半行、半张卡片时，先区分截图裁切、任意滚动位置和固定栏遮挡。只有画面能稳定指出内容包围盒与固定栏重叠、或有多帧/运行态证据时，才能确认遮挡；单帧边缘裁切只能列为待验证，不得直接定为 P0/P1。

再按 [desktop-review-rubric.md](desktop-review-rubric.md) 检查当前画面可见的页面结构、浮层边界、桌面密度和状态表达。不要用无法从画面验证的键盘、关闭或网络条目定性。

## 三、判定问题

每个问题包含：

| 字段 | 要求 |
|---|---|
| 位置 | 页面区域或可见控件 |
| 画面事实 | 只写截图中能指出的现象 |
| 影响 | 对识别、阅读、操作效率或一致性的影响 |
| PC 预期 | 可观察的桌面端结果，不锁死实现 |
| 严重度 | P0–P3 |
| 置信度 | 高 / 中 / 低，并说明证据限制 |

无法确认交互时，不写“点击无效”“无法关闭”或“请求失败”。改写为可交接的待验证项：

1. **验证问题**：具体要确认什么。
2. **验证动作**：点击、键盘、调整视口或查看运行日志的步骤。
3. **判定标准**：什么结果算通过，什么结果算失败。

## 四、输出

1. 一句话结论，明确这是静态截图评审及其证据范围。
2. 按影响排序的 5–10 个问题；证据不足时宁缺毋滥。
3. 最值得先改的 3 项，主导比例、空置持久区域、核心入口发现性和空间回收问题优先。
4. 可直接交给 E2E 走查的待验证清单。

截图评审到此结束。除非任务明确进入下一阶段，不执行点击遍历、Console/Network 检查或回归判定。
